## Qué enseña esta publicación

Panel editorial de las cuatro fases del producto. La geometría mostrada es una ilustración, no un proyecto del usuario.

El escaparate explica capacidades y evidencia de entrega sin distribuir escenas privadas, herramientas de licencia ni componentes internos.

## Guion del caso de estudio

Este guion sirve para explicar el recorrido documentado y preparar una demostración controlada. No afirma que se haya ejecutado completo durante esta publicación.

1. **Construir el espacio.** Observar: Organización de estancias, objetos y referencias de trabajo.
2. **Definir su ambiente.** Observar: Acabados, luz y recursos visuales para construir una propuesta.
3. **Diseñar el recorrido.** Observar: Presentación navegable con puntos y capítulos de visita.
4. **Preparar la presentación.** Observar: Preparación de fotografías, vídeo y documentos de presentación.
